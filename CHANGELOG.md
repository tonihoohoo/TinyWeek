# Changelog

Each release on GitHub shows the section for its version, and TinyWeek shows
it in **Check for updates** before you update. Add a section here before
changing `VERSION`; the release is not published without one.

## 1.3.0

- Changed: the date window and all update messages follow the Windows light or
  dark mode and high contrast, in the Windows 11 style with the accent colour
  on the main button. Screen readers read them and Ctrl+C copies their text.
- Removed: **Refresh** from the menu. The week number updates by itself at
  midnight, after sleep and when the clock changes.

## 1.2.1

- Changed: the "wk" label is larger, so it is easier to read next to the
  week number.

## 1.2.0

- New: **Show "wk"** in the menu draws a "wk" label above the week number.
- Changed: the smallest size, 60 %, is removed. Sizes are now 100, 90, 80 and 70 %.
- New: **Check for updates** shows what has changed before you update.
- Simpler, step-by-step install instructions in the README.

## 1.1.0

- New: **Check for updates** in the menu downloads and installs the latest
  version, after checking that the file is intact.
- Fixed: the right-click menu is now dark on a dark taskbar.

## 1.0.0

- First release: the ISO week number in the Windows taskbar, with adjustable
  size and weight, system font, light/dark taskbar support and
  **Start with Windows**.
